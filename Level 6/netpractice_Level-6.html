Subnet Game – Level 6

Goal: connect a local web server (Host A) to the Internet via router R, using default routes 0.0.0.0/0 and a return route on the Internet router for the public block.

1. Core concept of Level 6

Here you connect a local machine A to “Somewhere on the Net” (for example 8.8.8.8). Three things must be correct:

  • Host A and router interface R1 must be in the same subnet (same LAN).
  • Host A must have a default route 0.0.0.0/0 pointing to R1.
  • Router R must have a default route to the Internet, and Internet router I must have a route back to your public block (59.254.83.x).

Local LAN – Host A & R1 LAN A

You copy the mask from R1 to A1 and choose a valid IP in the same /25.

  • A1: 59.254.83.227, mask 255.255.255.128 (/25).
  • R1: 59.254.83.226, mask 255.255.255.128 (/25).
Mask /25 → 255.255.255.128 Last-octet blocks: 0–127, 128–255 A1 = 59.254.83.227 → in 128–255 block R1 = 59.254.83.226 → same block Network : 59.254.83.128 Broadcast : 59.254.83.255 Usable : 59.254.83.129 → 59.254.83.254

Both A1 and R1 lie in the subnet 59.254.83.128/25, so A can use R1 as its local gateway.

Router R ↔ Internet router I WAN

Router R connects to Internet router I on another network. The exact mask is given by the game (here /28), but the idea is:

  • R2: 163.172.250.12, mask 255.255.255.240 (/28).
  • I1: 163.172.250.1 (gateway side of the Internet router).
Router R default route: 0.0.0.0/0 => 163.172.250.1 (via R2) Internet router I: 59.254.83.0/24 => 163.172.250.12

So R sends any “unknown” traffic to 163.172.250.1, and the Internet knows to send any 59.254.83.x traffic back to 163.172.250.12 (R2).

2. Default routes on A and R

Host A routing table host routing

A only needs one extra rule besides its own subnet: the default route.

On Host A (web server): 0.0.0.0/0 => 59.254.83.226 via A1

Meaning: “If the destination is not in my local subnet 59.254.83.128/25, send to 59.254.83.226,” which is R1.

Example – A sends to 8.8.8.8: 8.8.8.8 ∉ 59.254.83.128/25 → match 0.0.0.0/0 → send to gateway 59.254.83.226 (R1)

Router R routing table router routing

Router R knows its directly connected networks (LAN 59.254.83.128/25 and WAN 163.172.250.x/28), and you add a default route toward the Internet:

On Router R: 0.0.0.0/0 => 163.172.250.1 via R2

So any destination that is not LAN A and not the WAN subnet is forwarded to the Internet router I at 163.172.250.1.

3. Internet router return route

Why 59.254.83.0/24 on I? return path

The Internet must know how to send packets back to Host A. That is done with a route on router I:

On Internet router I: 59.254.83.0/24 => 163.172.250.12

This covers all addresses 59.254.83.0 – 59.254.83.255, including A (59.254.83.227) and R1 (59.254.83.226). So any reply to 59.254.83.x will be sent to 163.172.250.12 (R2), and then routed to R1 and A.

End-to-end path summary flow

A -> 8.8.8.8: A: 8.8.8.8 not in 59.254.83.128/25 → default 0.0.0.0/0 → 59.254.83.226 (R1) R: 8.8.8.8 not local → default 0.0.0.0/0 → 163.172.250.1 (I) I: delivers to "Somewhere on the Net". 8.8.8.8 -> A (59.254.83.227): I: 59.254.83.227 matches 59.254.83.0/24 → send to 163.172.250.12 (R2) R: sees 59.254.83.227 in LAN A → forward via R1 to A

4. Reading the simulator logs

Forward way – A → Somewhere on the Net logs

forward way : A -> Somewhere on the Net (8.8.8.8) on A : packet accepted on A: destination does not match any interface. pass through routing table on A : route match 0.0.0.0/0 on A: send to gateway 59.254.83.226 through interface A1 on R : packet accepted on R: destination does not match any interface. pass through routing table on R : route match 0.0.0.0/0 on R: send to gateway 163.172.250.1 through interface R2 on I : packet accepted on I: destination IP reached

You see clearly both default routes being used: first on A (to R1) then on R (to the Internet router I).

Reverse way – Internet → A logs

reverse way : Somewhere on the Net -> A (59.254.83.227) on I : packet accepted on I: destination does not match any interface. pass through routing table on I : route match 59.254.83.0/24 on I: send to gateway 163.172.250.12 through interface I1 on R : packet accepted on R: send to R1 on A : packet accepted on A: destination IP reached

Here the Internet router uses the route 59.254.83.0/24 => 163.172.250.12 to send the reply back into your network; then R forwards it to A.

5. How to explain Level 6 in the evaluation

Your oral summary oral

“In Level 6 I connect a local host A to the Internet. First I put A and the router interface R1 in the same LAN by using the mask 255.255.255.128 (/25) with addresses 59.254.83.227 for A and 59.254.83.226 for R1 in the subnet 59.254.83.128/25.

Then I configure routing. On A I set a default route 0.0.0.0/0 pointing to 59.254.83.226, so any destination outside the local /25 is sent to R1. On router R I set a default route 0.0.0.0/0 pointing to the Internet router 163.172.250.1 via interface R2. On the Internet router I I add a route 59.254.83.0/24 via 163.172.250.12 so that replies to any 59.254.83.x address are sent back through my router. As a result, when A sends to an external IP like 8.8.8.8, the traffic goes A → R1 → R2 → Internet, and the reply uses the 59.254.83.0/24 route to return to R → R1 → A.”
