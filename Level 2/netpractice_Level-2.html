Subnet Game – Level 2

Goal: fix masks, avoid loopback, and place each pair of hosts in the same subnet.

1. What Level 2 teaches

This level introduces two subnet masks: /27 (255.255.255.224) and /30 (255.255.255.252), and also shows that 127.x.x.x is a loopback range and cannot be used as a real host IP.

A & B (/27) hosts

  • Mask: 255.255.255.224 (/27)
  • B1 fixed IP decides subnet: 192.168.29.222
Network: 192.168.29.192/27 Broadcast: 192.168.29.223 Usable: 192.168.29.193 → 192.168.29.222 A1 = 192.168.29.221 (/27) B1 = 192.168.29.222 (/27)

A1 and B1 now share the same /27 block (192.168.29.192–223).

C & D (/30) hosts

  • Mask: 255.255.255.252 (/30)
  • 127.x.x.x is INVALID → move to another block.
Chosen block (/30): Network: 126.0.0.0 Broadcast: 126.0.0.3 Usable: 126.0.0.1, 126.0.0.2 C1 = 126.0.0.1 (/30) D1 = 126.0.0.2 (/30)

C and D are now valid hosts in the same /30 subnet.

Subnet math – /27 subnet

Block size = 32 Ranges: 0–31, 32–63, ..., 192–223 B1 = 192.168.29.222 → in block 192–223

Any address 193–222 works for A1.

Subnet math – /30 subnet

Block size = 4 Only 2 usable hosts per block. Chosen block: 126.0.0.0–3 Usable: 1, 2

We avoid loopback and pick a clean /30 subnet.

Simulator logs logs

forward way : B -> A packet accepted → send to B1 A: packet accepted → destination reached

This confirms the pair is in the same subnet and reachable.

How to explain Level 2 in exam oral

“Left side uses mask /27 (255.255.255.224). B1 is in block 192–223, so I put A1 as 192.168.29.221 inside the same block. Right side uses /30; 127.x.x.x is loopback, so I move both hosts into valid block 126.0.0.0/30 with usable hosts .1 and .2. Now both pairs are in the same subnet and communicate.”
