NetPractice Cheat Sheet

Beginner guide to IPv4, subnetting, routers and gateways – tailored for the 42 NetPractice project.

1. IPv4 Address – The Basic Object

An IPv4 address has the form A.B.C.D, for example 192.168.1.10.

Each part A, B, C, D is an integer in [0, 255].

Every device in a network needs:

IP address

Subnet mask

Gateway (only if it talks to other networks)

2. Subnet Mask – Defines the Network Size

The subnet mask decides how the IP space is split into:

Network part (fixed)

Host part (variable)

MaskCIDRHosts / subnet
255.255.255.0/24254
255.255.255.128/25126
255.255.255.192/2662
255.255.255.224/2730
255.255.255.240/2814
255.255.255.248/296
255.255.255.252/302
Key idea: a “bigger” mask (more 255’s, larger /number) means a smaller network (fewer hosts).
Example: /24 is larger than /30.

3. Network, Broadcast, Host Range

Every subnet contains:

  • Network address – first address, cannot be assigned to devices.
  • Broadcast address – last address, cannot be assigned to devices.
  • Usable host addresses – all addresses in between.
Network: 192.168.1.0/24 Addresses: 192.168.1.0 ............. 192.168.1.255 [Network] 192.168.1.0 ❌ cannot use [Host] 192.168.1.1 ✅ usable [Host] 192.168.1.2 ✅ usable ... [Host] 192.168.1.254 ✅ usable [Broadcast] 192.168.1.255 ❌ cannot use

4. “Same Network” Rule (Most Important for NetPractice)

Fundamental rule

Two devices can communicate directly (no router) if and only if:

  • They have the same subnet mask, and
  • Their IPs belong to the same network address.

Example A – Same network (/24)

Mask: 255.255.255.0 (/24)

IPs: 192.168.1.5 and 192.168.1.200

Network = 192.168.1.0/24. Both are inside 1.* ⇒ same network ⇒ direct communication.

Example B – Two /25 networks

Mask: 255.255.255.128 (/25) ⇒ last octet split into two blocks:

RangeNetwork
0 – 127first /25 network
128 – 255second /25 network

IPs: 10.0.0.50 (block 0–127) and 10.0.0.130 (block 128–255)

➜ Not the same network ⇒ need a router between them.

5. Visual Device Diagram

[ PC1 ] --- [ Switch ] --- [ Router ] --- [ Switch ] --- [ PC2 ] PC1: 192.168.1.10 /24 Gateway: 192.168.1.1 Router left interface: 192.168.1.1 /24 Router right interface: 10.0.0.1 /24 PC2: 10.0.0.10 /24 Gateway: 10.0.0.1

Explanation: PCs are in different networks (192.168.1.0/24 and 10.0.0.0/24). The router connects them. Each PC uses the router interface on its own network as gateway.

6. Routers & Gateways

A router has several interfaces; each interface:

  • Has its own IP address.
  • Belongs to a different subnet.
Gateway rule for PCs
  • If destination is in the same network → send directly to destination IP.
  • If destination is in another network → send to the gateway.

Gateway = IP address of the router interface on the PC’s network.

Gateway Example

PC: 192.168.0.10/24 connected to router interface 192.168.0.1/24

➜ PC gateway must be 192.168.0.1.

7. /30 Networks for Router–Router Links

/30 subnets are very small: 4 addresses total, 2 usable hosts. Ideal for point-to-point router links.

Network: 10.10.10.0/30 Addresses: 10.10.10.0 10.10.10.1 10.10.10.2 10.10.10.3 Network = 10.10.10.0 (not usable) Router A = 10.10.10.1 (usable) Router B = 10.10.10.2 (usable) Broadcast = 10.10.10.3 (not usable)

8. Typical Errors in NetPractice

  • Gateway not in the same subnet as the PC.
  • Two router interfaces configured in the same subnet (overlap).
  • Using the network address or broadcast address as a host IP.
  • Different subnet masks for devices that are supposed to be in one LAN.

9. Fast Algorithm for Each Level

  1. Identify masks on all links.
  2. Group devices that must share a LAN and choose consistent subnets.
  3. Assign router interfaces first (one IP per subnet).
  4. Assign PC IPs in the correct subnet (not network/broadcast).
  5. Set gateways on PCs = router IP on their LAN.
  6. Use “Check again” in the interface and read the error messages.
